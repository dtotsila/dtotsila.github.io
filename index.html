Projects

Spam or Ham

github.com/dtotsila/spam_or_ham

Spam or Ham message classification project.

This spam/ham classification project uses machine learning algorithms to accurately identify spam messages. The project is designed to take in text input, such as an email or text message, and classify it as either spam or ham (not spam). The model was trained on a large dataset of labeled messages, allowing it to make accurate predictions on new, unseen data. The project also includes a simulated client-server chat where multiple users can communicate and the server prevents the display of spam messages

Keywords: Python Machine Learning, Pytorch, Classification, PyQt5.
